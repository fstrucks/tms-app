Today postmarkSend attaches only the filled packet PDF. The build adds the vault’s current docs as extra Postmark attachments (one PDF each; photos converted to PDF). Each is a checkbox, pre-ticked when on file. Unticking is per-send only.
Warnings, not blocks: missing doc → greyed row with a link; expired COI or gap notes from coiGaps (with the load date) → amber note. Expired COI is unticked by default (pick 4).
Who can see the docs: the server route reads the owner’s vault with the service client filtered to user_id = owner, the same pattern as the Truck tab. Dispatcher/management use the owner’s documents. Drivers can only view them.
Size guard: Postmark caps a message at 10 MB, so the draft shows the running total and blocks sending above the cap.
